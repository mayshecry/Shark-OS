# SharkOS Desktop 12.2 — Erase and reinstall
Boot the desktop live ISO, choose **Install to disk**, select a disk and check its number, model and capacity. Type `install N` (N is the displayed disk number). If the blank check finds data or cannot read the old contents, the installer stops before writing. Type `erase N` at this second prompt to replace the partition table and operating system, or press Esc/Enter alone to cancel without writing. A different number cancels too.

Back up first: after confirmation even an unsuccessful install may destroy data. This is not secure erase or hardware repair. Force applies only to the old-content check. The image checksum, device eligibility, capacity and write/read-back checks remain mandatory. The installer writes the new boot record last. On a larger target, forced replacement also clears and verifies the last sector to invalidate a possible backup GPT header; other sectors beyond the installation are not scrubbed. The desktop refuses an active FAT mount on the target and will not run from an installed session. Server CLI images are unchanged.

Verification: `make test-install` includes simulated unreadable media, corrupt read-back, write errors and cancellation. `python3 tests/qemu_force_install.py --iso-ram 96 --bios-ram 48` checks wrong-number refusal, Esc, sector comparison, and disk-only BIOS boot. For UEFI/AHCI run `MEM_PROFILE=efi python3 tests/qemu_force_install.py --ahci --iso-ram 192 --efi-ram 192`. The BIOS/IDE guest reported a read-back failure during one parallel run and correctly stopped; its standalone rerun passed. No physical disk was used.
